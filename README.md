# scan-ocr

スキャンPDF・画像から、1回のOCRで3つの成果物を作るローカルWebアプリです。

- **テキスト乗せPDF** … 元の見た目のまま＋透明テキスト層（検索・コピペ可能）
- **Markdown** … 全ページ結合のテキスト（見出しは自動でH1）
- **JSON** … 段落・表・単語ボックスなどOCRの構造化結果一式

OCRエンジンは [YomiToku](https://github.com/kotaro-kinoshita/yomitoku)（日本語文書特化）。ライセンスは CC BY-NC-SA 4.0（**非商用利用のみ**）。

**処理はこのパソコンの中だけで行われます。** アップロードした文書が外部に送信されることはありません。

## ダウンロードして使う

exe配布は今のところありません。Pythonを使ってこのパソコンで動かす形になります。少し手間がかかりますが、以下の手順どおりに進めれば大丈夫です。

### 必要なもの

- Windowsパソコン
- Python 3.10以降
- インターネット接続（AI関連のライブラリをダウンロードするため、初回のインストールに数GB・10〜20分程度かかります）

### 1. Pythonをインストールする（すでに入っていれば飛ばしてください）

[python.org](https://www.python.org/downloads/) から最新版をダウンロードしてインストールします。インストール画面の最初に出る **「Add python.exe to PATH」（PythonをPATHに追加する）に必ずチェックを入れてください。** これを忘れると、あとの手順でエラーになります。

### 2. コードをダウンロードする

[https://github.com/minnanosaiban/scan-ocr](https://github.com/minnanosaiban/scan-ocr) を開き、緑色の **「Code」** ボタン →「Download ZIP」でダウンロードします。

ダウンロードしたZIPファイルを右クリック →「すべて展開」で、好きな場所（デスクトップなど）に展開してください。

### 3. 必要なライブラリをインストールする

展開してできたフォルダ（`scan-ocr-main`）をエクスプローラーで開き、上のアドレスバーをクリックして `cmd` と入力し、Enterキーを押します。黒い画面（コマンドプロンプト）がそのフォルダで開きます。

その画面に、次のコマンドを入力してEnterキーを押します。

```
pip install -r requirements.txt
```

たくさん文字が流れますが、そのまま待ってください（数GBのダウンロードがあるため10〜20分程度かかります）。最後に `Successfully installed …` のような表示が出れば完了です。

> 「`'pip' は、内部コマンドまたは外部コマンドとして認識されていません」と出た場合は、手順1のPythonインストール時に「Add python.exe to PATH」にチェックを入れ忘れています。Pythonを入れ直してください。

### 4. 起動する

フォルダの中にある **`run.bat`** をダブルクリックします。黒い画面が開いたまま、自動的にブラウザで http://127.0.0.1:8791 が開きます。

**この黒い画面は、使い終わるまで閉じないでください。** 閉じるとアプリが終了します（終わるときは画面を閉じるか、画面内で何かキーを押します）。

### 5. デスクトップにアイコン付きのショートカットを置きたいとき

同じフォルダの中の `デスクトップにショートカット作成.bat` をダブルクリックしてください。「scan-ocr」というアイコン付きショートカットがデスクトップにでき、次回からはそこをダブルクリックするだけで起動できます（`run.bat`を指すだけなので、何度実行しても上書きされるだけで安全です）。

## 使い方（アプリの画面操作）

入力は2通り：
- **1ファイル**：PDF・画像をドロップ／クリックして選択
- **フォルダ一括**：「フォルダを選ぶ」でローカルフォルダを指定すると、直下のPDFすべてをまとめてOCR
  （サブフォルダは対象外。前回このアプリが書き出した`*_ocr.pdf`は自動で対象から除外）

共通の設定：
- **作成するファイル**：テキスト乗せPDF／Markdown／JSONから1つ以上選ぶ
  （OCR自体は選んだ形式によらず1回だけ行われ、選ばなかった形式の書き出しだけを省く）
- **ファイル名**：`{stem}`(元のファイル名)・`{date}`(実行日)が使えるパターン。既定は`{stem}_ocr`
  （出力先が入力元と同じフォルダになる場合に備え、既定で必ず元のファイル名と変わるようにしている。
  `{stem}`だけを指定するなど元ファイルと同名になる設定は、上書き防止のためエラーになる）
- **保存先フォルダ（任意）**：指定すると生成物がそのフォルダへ直接書き出される。
  未指定の場合、1ファイルモードはダウンロードのみ、フォルダ一括モードは入力フォルダと同じ場所に保存
- 保存先・入力元フォルダの選択はどちらもOSネイティブのフォルダ選択ダイアログ（サーバー=このPC上で開く）

GPU非搭載パソコンではCPUでの処理になり、1ページあたり数秒〜数十秒かかります（「軽量モデル」チェックで多少速くなります）。

## 構成（開発者向け）

```
app.py            FastAPIサーバー（アップロード受付・進捗・ダウンロード・フォルダ一括処理）
ocr_pipeline.py   OCR本体（YomiToku呼び出し、3形式書き出し、ファイル名パターン解決）
static/           フロントエンド（素のHTML/CSS/JS）
jobs/             1ファイルモードのアップロード・出力の一時保存先（.gitignore対象、コミットしない）
```
